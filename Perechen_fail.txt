_2D_Atlas_main.py - точка входа: инициализация базы данных (создание таблиц, если их нет) и запуск главного окна
ai_generate.py - логика ИИ-генерации кадров: референс, промпты, вырезание фона, запись кадров в базу, сборка атласа (без GUI)
animation_viewer.py - анимационный экран: нарезка выделенной области на кадры, просмотр анимации, выравнивание и сохранение кадров
atlas_interface.py - начальный экран (главное окно AtlasInterface): панель инструментов, выбор атласа, запуск остальных окон
atlas_loader.py - загружает изображение атласа
class_selector.py - работа с классами кадров
database.py - база данных SQLite (таблицы characters/frames, создание схемы)
dataset_export.py - экспорт датасета для обучения LoRA: кадры из базы -> папки png + txt-caption
enhance_window.py - окно улучшения изображения: резкость, контраст, яркость
export_window.py - окно "Модуль ИИ": экспорт датасета и запуск обучения в отдельном потоке
file_selector.py - выбор файла атласа и вызов редактора (FileSelector)
frame_detector.py - детекция кадров спрайт-атласов по альфа-каналу (поиск рядов и границ кадров)
generate_window.py - окно "ИИ-генерация кадров": референс, персонаж, классы поз, генерация и сборка атласа
image_grid.py - работа с сеткой (сетки поверх атласа)
image_saver.py - сохраняет выделенную область изображения в формате .png
image_splitter.py - основной модуль разрезки атласа: классы из базы, кнопки классов, нарезка и сохранение кадров
language_manager.py - мультиязычность (русский/английский), паттерн "наблюдатель"
lora_train.py - подготовка обучения LoRA через kohya_ss: пресеты, конфиг TOML, проверка готовности (без GUI)
paint_app.py - редактор кадров (рисование): элементы управления для рисования
results_viewer.py - обработка базы данных: таблица кадров, редактирование классов, удаление, экспорт
sd_generate.py - воркер генерации кадров через diffusers: запускается python из venv kohya_ss отдельным процессом
sound_manager.py - фоновая музыка (pygame)
theme_engine.py - скины для интерфейса (темы оформления)
train_window.py - окно обучения LoRA: параметры, лог, запуск kohya_ss
